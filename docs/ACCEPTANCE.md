# Mac 与配对真机验收清单

以下项目均为待执行，不是已通过测试。

| 场景 | 可观察的验收结果 |
| --- | --- |
| 两个 target 构建 | iOS、watchOS 均无编译/链接错误，手机正确嵌入 Watch App |
| 首次拒绝麦克风 | 明确提示权限，未出现伪录音状态 |
| 手机录音 2 分钟 | 多个片段可播放，顺序正确；测量并记录分段间隙 |
| 手表断开手机后录音 | 音频留在手表；连接恢复后可手动重试同步 |
| 接收阶段杀死手机 App | 手表未获保存回执时继续保留文件；重开后可恢复导入 |
| 重传同一 UUID | 手机只保留一条记录 |
| 删除后迟到重传 | 已删除记录不会重新出现 |
| 音频落盘、索引未写时杀进程 | 重开后恢复可播放文件；无法恢复则明确记录失败 |
| 关闭网络后中文/英文转写 | 有本地模型时成功；无模型时说明不支持，无音频上传 |
| 转写期间修改标记 | 转写完成后标记仍保留 |
| 转写期间删除记录 | 完成回调不恢复记录 |
| AI 未配置/错误 Key/429/超时 | 清晰错误，可重试，无无限加载 |
| 切换 AI 服务地址 | 不复用旧服务地址的密钥 |
| AI 返回 302 | 不跟随重定向，不向新目的地发秘密 |
| AI 给出伪造引用 | 不生成该引用的来源跳转 |
| 发送预览 | 与实际发送的片段内容一致，不附原始音频 |
| 锁屏/手腕放下/来电/Siri | 记录是否持续、是否丢片，打断后不偷偷恢复录音 |
| 1/4/8 小时录音 | 测量电量、温升、磁盘、同步积压与音频缺口，不外推未测试续航 |
| 导出与删除 | 导出文件可播放；本机删除移除音频和转写 |
| 动态字体和 VoiceOver | 核心操作可读可点、可辅助访问 |

发布门槛：构建、XCTest、配对真机核心流程均通过；已知音频缺口和数据丢失风险解决或明确限制产品功能；另行完成上架隐私与签名配置。
